# Adroit - AI Marketing Agency Platform

## YouTube Video Title

## Video Description

```
Adroit is an autonomous AI marketing agency platform that democratizes marketing for small businesses using AI and blockchain technology.

🎯 What is Adroit?
Adroit provides end-to-end marketing services for SMEs who cannot afford traditional marketing agencies. It uses AI to manage advertising campaigns, create content, optimize SEO, handle social media, and execute full marketing strategies — all with autonomous USDC payments on Arc blockchain.

✨ Key Features:
• AI Marketing Agent with 31+ tools for Meta Ads management
• Social Login with non-custodial wallets on Arc blockchain
• Virtual cards for ad spend (funded with USDC)
• Crosschain transfers via Circle Gateway
• Agent-to-agent commerce with x402 micropayments
• Real-time dashboard with campaign analytics

🔗 Links:
• Live Demo: https://adroit-one.vercel.app
• GitHub: https://github.com/AbelOsaretin/Adroit
• Presentation: https://docs.google.com/presentation/d/13SG8eeR0QpSDNT7B7_ZJwQ60WVRg09XenUY_UXn31mQ/edit

🛠️ Tech Stack:
• Next.js 16 - Frontend framework
• Mastra AI - AI agent framework
• Circle - User-controlled wallets, Gateway, CCTP
• Meta Ads SDK - Campaign management
• Turso/LibSQL - Database
• Arc Blockchain - USDC payments
```
